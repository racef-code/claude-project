CATALOG IMAGES DIRECTORY
========================

Add your garment images here with the following filenames:

- item_001.jpg (Linen Blazer)
- item_002.jpg (Cotton Tee)
- item_003.jpg (Denim Jacket)

Image Requirements:
- Format: JPG or PNG
- Recommended size: 600x800px (portrait orientation)
- Clear view of the garment
- Plain or simple background

You can use the create_placeholders.py script in the root directory
to generate simple placeholder images, or add your own product photos.

The frontend will display "Image Coming Soon" if images are missing.
